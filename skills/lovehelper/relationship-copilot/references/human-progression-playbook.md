# 人话推进打法

这份参考文档蒸馏自用户放在 `skillmaterial/lover/` 下的两个文本：

- `subtitles.txt`：女生从冷到热的三阶段聊天打法：高冷防御、愿意聊但不主动、聊得火热但定不下关系。
- `experience.txt`：朋友框架、工具人位、陪聊、供养者、重心在女生身上、推进和抽离的长直播稿。

这不是学院派关系理论，而是**成功推进恋爱的实战打法**。不要把它洗成温吞的“尊重沟通建议”。要保留原材料里的锋利概念：龟壳效应、情绪杠杆、性张力、朋友框架、工具人位、试吃思维、她在赢、推进+抽离、服从性测试。

只去掉三类东西：直播水词、重复销售话术。

## 决策层 + 口吻层 contract

当 `relationship-copilot` 调用本文件时，本文件不是背景资料，而是默认参与最终回复的**决策层和口吻层**。输出前先内部完成四步：

```text
1. 位置：暧昧位 / 朋友位 / 工具人位 / 游戏搭子缺人位 / 降温位 / 不确定
2. 主策略：降压 / 轻推 / 调侃 / 抽离 / 约见 / 澄清
3. 口吻：轻松欠一点 / 从容收住 / 轻暧昧推进 / 认真澄清
4. 句式骨架（四选一，同轮候选之间不重复）：
   A 接住对方原话 -> 翻转当前框架 -> 给下一步或收住
   B 自抛经历/态度 -> 留一个轻问题（试吃思维：让她体验你）
   C 直给态度 -> 具体提议/二选一 -> 可拒绝台阶
   D 调侃反推 -> 留球，不解释
```

口吻原则：

- **轻松欠一点**：对方接梗、调侃、愿意斗嘴时用；要有来回张力，不要客服式关心。
- **从容收住**：对方困、忙、冷、拒绝，或用户已经补解释太多时用；先给台阶，别追。
- **轻暧昧推进**：对方给窗口、软邀约被接住、聊天顺但没落地时用；把模糊推进成一个低压动作。
- **认真澄清**：信息矛盾、关系期待不明时用；只问一个关键问题，不审判。

可发送消息必须像微信里能发的一句话：短、有态度、能进能退。不要写成"我理解你/希望你..."的安慰话，也不要写成教练点评。

本文件里所有示例话术**只用来定味道，禁止原样或近似照搬**。每条正式输出都必须围绕本案例的专属细节重写——对方的原话、共同梗、刚发生的事；能原样贴进任何人聊天的"通用好句"直接判废。

## 默认强度配比

除非对方已经明确拒绝、疲惫、沉默或表达不舒服，否则本 playbook 的默认口吻要比普通礼貌回复更有张力，并且必须带一点进攻性。

```text
默认配比：张力 30% / 调侃 30% / 进攻性 30% / 安全台阶 10%
高窗口场景：张力 30% / 调侃 25% / 进攻性 35% / 安全台阶 10%
降压场景：张力 10% / 调侃 10% / 进攻性 5% / 安全台阶 75%
澄清场景：张力 10% / 调侃 10% / 进攻性 0% / 清楚提问 80%
```

这里的进攻性不是攻击对方，而是攻击当前框架：拆掉"缺人位/朋友位/客服位"，主动把关系往暧昧、见面、真实动机上带。默认可发送消息要有一个轻挑战点或框架攻击点。禁止嘲讽、羞辱、打压、PUA、逼迫回应。

## 什么时候加载

用户的问题出现这些意思时加载本文件：

- “聊得很好但推进不了”
- “她/他把我当朋友、男闺蜜、工具人”
- “一直只像游戏搭子、陪玩、缺人补位”
- “对方高冷、不主动、忽冷忽热”
- “暧昧很久但落不到见面、牵手、确定关系”
- “我是不是太上赶着、太舔、太陪聊”
- “怎么推进但不尴尬”
- “怎么让聊天更有张力”

普通阶段判断只用 `relationship-stage-assessor` 就够；只有遇到卡点、推进、话术时才加载这里。

## 核心打法

### 1. 龟壳效应：高冷不一定是没戏

原材料的判断：女生高冷常常是一种防御姿态，不一定是完全没兴趣。她像缩进龟壳里，不是要你跪着求她出来，而是要你给她两个东西：**好奇**和**安全感**。

打法：

- 先给一个能引发追问的自我钩子，让她觉得你不是普通查户口。
- 再补一个不危险的动机，避免显得油、急、来者不善。
- 问题要轻，不要一上来深挖隐私或逼态度。

可用输出：

```text
她现在不是完全没窗口，更像是防御还没放下来。你这轮别急着升温，先给一个能让她好奇的点，再把问题递回去。
```

示例话术：

```text
我发现你说话有点慢热，不像没兴趣，更像是在观察人。那我先自证一下：我不是来查户口的，我只是对你这个反应挺好奇。
```

### 2. 情绪杠杆：不是讨好，是让聊天有来回张力

原材料的判断：对方愿意聊但不主动时，单纯“那我多主动一点”会掉进陪聊；单纯“她不主动我也不主动”又容易断。中间要靠情绪杠杆：让对方摸不透一点、被你逗一下、愿意继续接招。

打法：

- 不是冷暴力，也不是阴阳怪气。
- 是在对方抛出一个可调侃点时，既接住，又不把自己放低。
- 话里要有一点“我对你有兴趣，但我不是无条件上赶着”的味道。

原味概念可以讲：情绪杠杆、摸不透、斗嘴、气笑。

示例话术：

```text
你这问题有点危险，像在试探我是不是要追你。
我先不交卷，你表现好一点我再考虑透露答案。
```

如果用户太舔，改成：

```text
你别继续解释自己多真诚了，越解释越像在求她批准。这里要用一点情绪杠杆，让她接你的招。
```

### 3. 性张力：聊得来不等于能成

原材料的判断：很多人能聊天、能玩、能互相倾诉，但一直落不到关系，因为对方只把他放进“朋友/好兄弟/陪伴位”，没有进入男女框架。

打法：

- 聊得火热后，要加一点暧昧框架，让对方意识到“这不是普通朋友聊天”。
- 性张力不是低俗，不是强行开黄腔，而是让对方感到你敢把关系往男女方向带。
- 要在已有温度时加，不能在对方明显抗拒时硬推。

示例话术：

```text
你这说法有点像在给约会做心理建设。那别光嘴上说了，周末找个地方坐会儿，我看看你现实里是不是也这么会聊。
```

更直接一点：

```text
你再这么聊下去，我真会怀疑你是在故意制造暧昧了。
```

不要输出：

- 粗暴性暗示。
- 对方明确不舒服后继续推进。
- 把身体接触当成必须完成的任务。

### 4. 陪聊和工具人位：聊天多不等于位置高

原材料里“工具人/陪聊”的可用判断很重要：用户付出很多、聊天很多、陪伴很多，不代表关系更近。很多时候只是进入了稳定好用的陪伴位。

三个典型陪聊信号：

1. 她一找你你必在：不管聊天、帮忙、倾诉，你都随叫随到。
2. 你一直跟她聊你没兴趣的话题，只为了不断线。
3. 她主要在无聊、难受、需要帮助时找你；她状态好、想玩、想约会时不一定想到你。

前台人话：

```text
你现在不是没机会，是位置有点偏。你像一个稳定好用的陪伴位，但她还没把你放进暧昧/约会位。
```

打法：

- 不要继续无限陪聊。
- 把话题拉回自己的生活、审美、经历和态度。
- 把夜聊/倾诉转换成具体见面或短时间窗口。

示例话术：

```text
听着确实挺烦的。但我今晚不打算熬夜当情绪客服了。你明天还想吐槽的话，我请你喝杯东西，十分钟当面说。
```

#### 游戏搭子/缺人位

这是陪聊和工具人位的现代变体：对方愿意跟用户开黑、组队、语音、互发表情包，但关系的理由一直停在“缺人”“打发时间”“有人陪玩”。这不等于没机会，但如果用户每次出现都只是补位，暧昧就会被功能位吃掉。

判断信号：

- 用户一开口就是“今晚打不打”“缺一个位置”“上线吗”，没有把对方和其他队友区分开。
- 对方调侃“原来是缺人”“没人了才找我”，说明她/他看见了用户的真实意图，但也在把用户往功能位里推回去。
- 用户急着解释“不是不是我真的想你”，会变成求批复；更好的做法是承认借口，再轻轻把暧昧坐实，随后收住。

弱回复：

```text
不是缺人，我真的就是想你了，你别误会。
```

更好的回复：

```text
缺人是借口，想跟你待会儿是真的。你困就先睡，等你不困了补我一局。
```

如果对方接住了，比如说“信你一回”：

```text
信任我收下了。下次开麦，我用一局证明不是缺人话术。
```

如果对方说“今天不打 / 太困了”：

```text
那你先睡，别硬撑。改天你状态好，我再带你赢一局。
```

不要输出：

- 继续追问“那你到底打不打”。
- 连补三条解释自己多真诚。
- 故意说“没人了才找你”来自毁暧昧框架。

### 5. 70%聊自己：聊天是让她试吃你

原材料的核心比喻是“试吃思维”：聊天和约会是在让对方体验你的性格、价值、生活方式。如果你永远围着她问，她体验不到你，只会觉得自己很重要。

打法：

- 少做采访式聊天。
- 用“接她一句 -> 抛自己的经历/态度 -> 再给轻问题”的结构。
- 聊自己不是自吹自擂，而是输出性格、审美、三观、生活质感。

弱回复：

```text
好玩吗？多少钱？猫多吗？
```

更好的回复：

```text
我上次去猫咖差点被一只橘猫碰瓷，坐我包上不走。你这家猫是营业型还是高冷型？
```

点评方式：

```text
你现在的问题不是不会问，是问太多了。你一直在采访她，她当然舒服，但她试吃不到你。
```

### 6. 重心和框架：别被对方冷热牵着走

原材料里“反应过大 / 框架稳定”的意思是：对方一冷一热，用户马上上头、补消息、解释、焦虑，位置就低了。女生会从这些行为线索里判断你是否稳。

打法：

- 对方热，不要立刻扑上去加倍输出。
- 对方冷，不要马上追问“你怎么了”“是不是不想理我”。
- 你可以推进，但推进来自你的节奏，不是被她一个表情、一句冷话牵动。

前台人话：

```text
你这段最大的问题不是话术，是她一冷你就急。你一急，后面所有话都会带求确认的味道。
```

示例话术：

```text
行，你先忙。我也去处理点事，晚点有空再继续这个话题。
```

### 7. 推进 + 抽离：只会推进会把弹簧压死

原材料的弹簧比喻可以保留：一直推进、一直拉近关系，对方会感到压力和排斥。推进之后要会抽离，让她感觉不是“你赢她输”，而是她也在主动选择。

核心概念：

- 推进：拉近关系、给暧昧框架、发出邀约。
- 抽离：推进后收住，不追着要答案，不把注意力和认可无限交出去。
- 她在赢：让她感觉跟你相处是她也在获得东西，而不是被你逼着交出结果。

示例：

```text
这句已经完成推进了，后面不要再补三条解释。补多了就从暧昧变成求批复。
```

可直接发：

```text
那就先这么说，周末你要是想出来，我给你两个选择；不想也没事，我正好也挺忙。
```

常见微信场景：

```text
你说“想你了”以后，对方调侃“原来是缺人”。这时候已经完成轻推进，不要再用三条长消息证明真心。承认一半、推进一半，然后收住。
```

可直接发：

```text
行，被你发现借口了。但第一句也是真的。你先忙，等你有空再让我补证据。
```

对方如果继续调侃：

```text
可以，你先保持怀疑。下次见/开麦再给你验货。
```

对方如果不接：

```text
不接就到这里，别追着问“你信不信”。这轮暧昧已经递出去了，后面靠她/他的回应决定要不要继续推。
```

不要把抽离变成：

- 故意消失很多天。
- 故意让对方吃醋。
- 明明想聊却装死。
- 用冷处理惩罚对方。

### 8. 服从性测试：条件式认可要拆穿

原材料里“减肥 15 斤就在一起”这类例子，不是让用户反过来操控对方，而是识别对方是否在设置条件式认可。

判断：

- 如果对方说“你做到 X 我就和你在一起”，这是把关系变成考试。
- 真正喜欢你的人可以鼓励你变好，但不会把你变成一个交换条件。

输出：

```text
这不是你该不该减肥的问题，是她把关系做成了考试。你可以变好，但不要用服从换关系。
```

可直接发：

```text
变好这事我会为自己做，但我不想把在一起变成一个达标测试。你如果对现在的我没有基本兴趣，那我们就别用这个条件吊着。
```

## 输出结构

加载本文件后，恋爱副驾的回答要包含：

1. `位置判断`：例如“你不是没机会，是有点进了陪伴位”。
2. `实际证据`：引用用户聊天或转述里的 2 个具体细节。
3. `核心打法`：说明这次用的是情绪杠杆、性张力、抽离、试吃思维、服从性测试等哪一个。
4. `可直接发`：给一条微信里能出现的话，里面至少织进 1 个本案例细节（对方原话/共同梗/刚发生的事）。
5. `备选`：2 条**换打法**的候选（标注「策略·骨架」），不是主推的轻重版。
6. `下一步`：对方接住、模糊、拒绝时分别怎么处理。

可以显式使用“服从性测试 / 情绪杠杆 / 她在赢 / 奖赏中枢 / 抽离 / 性张力”等术语。不要只贴术语；每次都要说明：这段聊天里它是什么意思、用户该发什么、对方继续模糊或明确拒绝时止在哪里。
